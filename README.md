# cold-email-master

Justin's single cold email skill: an Executive Director plus a 12-agent team. It covers strategy (the attack plan), list and signals, research, copy (house frameworks with Buchan techniques in plain voice), deliverability, QC, replies and analysis. It builds the house-format frameworks doc v2 (10 frameworks, a follow-up each, 2 closers, 22 touches), with an Attack Plan, spin sets, an infrastructure and launch checklist, weekly health checks and an upgraded reply playbook.

**Private repo. It contains paid-course-derived Buchan material (`cold-email-master/references/buchan/`). Never make it public.**

- Skill: `cold-email-master/SKILL.md` (symlinked into `~/.claude/skills/` and the Hermes cold-email profiles)
- Verifier: `python3 cold-email-master/scripts/verify_doc.py "<doc>.md"` (`--legacy` for pre-v2 docs, `--leads out.json` for per-lead copy, `--grades` for the reading-grade table)
- Sources: `sources/videos/` (4 cleaned transcripts + `video-notes.md`)
- Why each rule won: `cold-email-master/references/conflict-resolutions.md`
